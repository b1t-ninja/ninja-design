# Ninja Design

> Empty your mind, be formless. Shapeless, like water. If you put water into a cup, it becomes the cup. You put water into a bottle and it becomes the bottle. You put it in a teapot, it becomes the teapot. Now, water can flow or it can crash. Be water, my friend.
>
> _Bruce Lee_

In an effort to streamline the development process, make my UIs more cohesive and create something useable no matter the context, I have built this UI library. \
Heavily inspired by other UI Libraries like MaterialUI. \
\
So far I have added only the most basic pieces, but they are also the most commonly used elements (at least for me).    

If you want to know more, feel free to check out the documentation.
